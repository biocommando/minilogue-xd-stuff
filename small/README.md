# Phase reset oscillator

This is an experiment about making as small binary as possible for a user osc that still is an unique and musically useful oscillator.
This is a square wave oscillator with adjustable pulsewidth and random phase reset to 0, which creates a glitchy and noisy texture.

Currently the built binary size is at 268 bytes.

### Parameters

#### Shape parameters
- Shape:
    * Phase reset frequency
- Shift + Shape:
    * Pulse width (shape LFO controls this)

#### User parameters
None
